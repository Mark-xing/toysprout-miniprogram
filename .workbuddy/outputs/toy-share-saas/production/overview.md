## 交付结论

在 MVP Web 版（36/36 回归验证通过）基础上，完成向**微信小程序原生 + 微信云开发**的生产级架构升级：

- **后端**：7 个微信云函数（auth/user/toy/swap/review/membership/upload），云数据库替代 SQLite，**本地集成测试 35/35 PASS**
- **前端**：11 个小程序原生页面（4主包+7分包），沿用 WarmTrust v2 设计令牌（WXSS 变量迁移），自定义组件化（toy-card 等）
- **P0 门禁**：emoji 图标 0 命中（含星级/勾选符号均已改为 SVG 矢量图标）、紫粉渐变 0、AI 模板味 0
- **支付/短信**：按您的决策，代码层标准化预留切点（`payService.js`/`smsService.js`），当前模拟实现，接入真实资质后只需替换内部实现，业务逻辑零改动

## 关键架构决策

1. **云函数拆分策略**：按业务域拆 7 个而非 28 个细粒度端点，每个内部用 `action` 分发，避免管理复杂度失控。
2. **无事务应对**：云数据库不支持跨文档事务，发起交换用"建记录+失败补偿回滚"策略；状态机流转用"前置条件更新"形成乐观锁。
3. **信用等级不落库**：云函数统一实时计算 `deriveCreditLevel()`，比 MVP 版 SQLite 生成列方案更彻底杜绝双口径问题。
4. **共享代码同步机制**：云函数各自独立打包，`cloudfunctions/_shared/` 作为源码，`scripts/sync-shared.js` 部署前同步。
