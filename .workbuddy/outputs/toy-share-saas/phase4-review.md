## 二、分维度详细依据

### 维度 1 · 设计哲学 4/5

**依据**
- 信任组件族（消毒报告卡 / 质检徽章 / 批次追溯条 / 安全标识组）作为一等组件在四页全部出现：
  - index：Hero 悬浮信任徽章（质检合格 TS-…、配送中、批次 BATCH-…）+ 安全标识组 4 卡 + "四道关"流程（index.html L45-47、L124-161、L418-451）
  - dashboard：订单卡内嵌消毒状态（消毒中/配送中/使用中·已消毒，L248-312）
  - toy-detail：完整消毒报告卡（含质检员工号 QC-071、批次编号）+ 批次追溯条 + trust-note（L94-184、L242-245）
  - rental：批次追溯条 + 退款保障卡（L181-221、L258-265）
- 品牌语汇统一：温暖暖米白底 + 珊瑚 CTA + 奶油黄点缀；文案直白具体（"好玩具，不用买。按月换着玩。"），无"解锁/赋能/一站式"等 AI 空泛词。
- Hero 视觉隐喻（"温暖的家 + 透明的工艺"）通过悬浮徽章直观呈现。

**减分点**
- 详情页"按月订阅 ¥59/月"与流程页套餐"年卡 ¥69/月"口径错位（详见 P1-2），使"性价比"价值主张在转化路径上失真。

**改进建议**
- 统一"玩具租赁价"与"订阅套餐价"两套口径的表达，明确"套餐内玩具含在订阅费中"，避免用户对价格产生误解。

### 维度 2 · 视觉层次 4/5

**依据**
- 落地页视线流：Hero（信任徽章）→ 安全标识组 → 玩具推荐 → 套餐 → 四道关 → 底部 CTA，主 CTA 每屏可见且唯一（Hero 2 个 CTA，套餐区各 1）。
- 详情页左图右信息 + 吸顶购买卡：图集 → 报告卡 → 追溯条 → 购买卡内 trust-note，决策点（吸顶卡）始终带信任锚点，转化心智成立。
- 仪表盘：统计块（3/在租/待归还/会员）→ 今日推荐 → 进行中订单 → 右栏会员/快捷/配送，主次分明。
- 字体阶梯（display/h1…caption/micro）与 tabular-nums 数字对齐执行到位。

**减分点**
- 落地页"四道关"连接线视觉断连（详见 P1-1），该区是品牌信任的核心章节，局部层级与精致度受损。

**改进建议**
- 修复连接线后此维度可升至满分。

### 维度 3 · 执行质量 3/5

**依据（做得好的）**
- 语义化标签齐全：header/main/section/article/aside/nav/footer；svg 均带 role="img"+aria-label，交互元素带 aria-label/focus-visible。
- CSS 变量消费纪律：styles.css 令牌与 phase2 §11 完全一致；页面内 raw hex 仅出现在 SVG 插画填充，且均为品牌色值。
- 状态三重编码（颜色+图标+文字）贯彻：消毒中（琥珀+计时器+文字）、配送中（蓝+卡车）、质检合格（绿+盾+文字）。
- 响应式预留：1023/767 断点 + prefers-reduced-motion 降级；批次追溯条移动端纵排降级符合 §9。
- 交互状态齐全：hover（卡片上浮/按钮变色）、focus-visible 焦点环、disabled 态。

**减分点（4 处明确缺陷）**
1. `styles.css` L317 `.report-step:not(:last-child)::after` 设 `left:60%;width:80%`，假定图标居中；落地页 L419-450 用 `style="margin-inline:0"` 将图标左对齐，连接线变成悬空线段，与图标脱节。
2. rental.html L150 将 2025-06-20 标注"周六"，实际为**周五**（已用系统日历核验；dashboard 的 06-14 星期六正确）。
3. 详情页与流程页订阅价/押金口径不一致，且"立即租"跳转不携带已选方案。
4. "确认订单"（rental.html L248）直接 href dashboard.html，无下单成功态，转化闭环缺失。

**改进建议**
- 见"问题清单"P1-1～P1-4 的代码级修复方案。

### 维度 4 · 特异性 4/5

**依据**
- 信任组件族具有一致且独特的视觉语言：报告卡左侧 4px 绿色标识条 + mono 报告编号 + 员工号背书 + 4 步时间戳；追溯条 6 节点（入库→消毒→质检→配送→使用中→归还复检）带呼吸动画进行态；质检徽章"浅底+深字+盾/勾"。
- 品牌专属命名：芽苗/枝叶/花蕾会员阶梯、"四道关"消毒话术、TS-/BATCH-/QC- 编号体系。
- 不会与通用 SaaS 模板混淆，能被识别为「现代亲子共享品牌」。

**减分点**
- 玩具插画为几何占位，个体辨识度一般（原型期可接受，生产期建议替换实拍图）。

**改进建议**
- 保留信任组件族不变；生产期将几何占位插画替换为真实产品摄影或更精致的品牌插画。

### 维度 5 · 克制 4/5

**依据**
- 大面积背景维持暖米白/纯白；品牌色仅作点缀（Hero 徽章、CTA、进度条），占比约 ≤15%。
- 底部 CTA 使用奶油→珊瑚暖渐变但配深炭文字，未违反"装饰彩底白字"禁令。
- 无 emoji 充当图标、无紫色/彩虹渐变、无冷黑阴影（全部 rgba(61,45,30,…) 暖棕调）。
- 悬浮信任徽章均为功能信息（质检编号/批次/物流），非装饰性。

**减分点**
- 玩具插画单张即用 4-5 个色相（黄/珊瑚/绿/蓝），全页饱和色相偏多；伟易达学习平板底用 danger-tint #FBE4DF（语义红被用于装饰），语义色使用边界略模糊。

**改进建议**
- 玩具插画背景统一使用品牌浅色（surface-muted / primary-tint / neutral-tint），避免 danger-tint 作装饰。

## 四、问题清单与修复方案

### P0（必须修复）
无。

### P1（建议修复 · 阻断 PASS 门控，4 项）

**P1-1 落地页"四道关"连接线断连**
- 位置：index.html L418-451 + styles.css L317
- 现象：`.report-step:not(:last-child)::after` 以 `left:60%;width:80%` 画线，其几何前提是图标居中（`margin-inline:auto`）；落地页将图标内联改为 `margin-inline:0` 左对齐后，连接线成为每格中部一条悬空横线，与图标无视觉关联。
- **修复方案（任选其一）**：
  - 方案 A（最小改动）：删除落地页四格的内联 `style="margin-inline:0;"` 与 `text-align:left`，让图标回到居中，直接复用报告卡的连接线逻辑；说明文字改用 `grid` 下左对齐子容器承载。
  - 方案 B（更稳）：为落地页"四道关"新建 `.sanitize-steps` 样式，不使用 `::after` 连线，改用四卡顶部独立短横线 `border-top`，彻底规避几何依赖。

**P1-2 详情页 → 流程页订阅价/押金口径不一致**
- 位置：toy-detail.html L219-240 vs rental.html L65-88、L239-245
- 现象：
  - 详情页"按月订阅 ¥59/月 · 押金 ¥200"、"按季 ¥49/月"；
  - 流程页默认勾选"年卡 ¥69/月 · 押金 ¥100"，订单摘要"首月合计 ¥169"；
  - 用户从详情页选"按月 ¥59"点"立即租"，跳转后变成年卡 ¥69+押金¥100，选择未保留。
- **修复方案**：
  - 统一口径：详情页租赁选项改为与流程页一致的"月卡 ¥89 / 季卡 ¥79 / 年卡 ¥69（押金 200/200/100）"，并将"玩具 ¥59/月"明确为"玩具租赁单价（非订阅会员价）"或直接删去，避免双价体系混淆。
  - 若保留玩具单价：流程页"确认订阅套餐"需通过 URL 参数（如 `rental.html?plan=month`）带入详情页所选方案并默认选中，押金随方案联动显示。

**P1-3 日历星期标注错误**
- 位置：rental.html L150
- 现象："已选 06-20（周六）"；2025-06-20 实际为**周五**（已核验，dashboard 的 06-14 星期六正确，两者互相印证出错）。
- **修复方案**：将文案改为"已选 06-20（周五）"，并复核日历网格中 20 日的落位与星期栏对应（当前网格行序与周五位置一致，仅标注文字需改）。

**P1-4 "确认订单"缺少成功反馈**
- 位置：rental.html L248
- 现象：主 CTA 直接 `href="dashboard.html"`，无下单成功态，用户无法确认提交结果，违背"透明可信"品牌基调。
- **修复方案**：新增确认页或弹层（建议独立 `success.html`）：
  - 展示订单号（如 `TS-20250614-0XXX`，mono 字体）、所选套餐/押金、预计送达日期；
  - 嵌入"本件消毒批次 BATCH-20250613-0421 已为你锁定"的信任提示；
  - 主按钮"查看我的订单 →"回仪表盘，形成闭环。

### P2（可选优化）

1. **报告卡时间戳 11px 偏小**：styles.css L324 `.report-step .step-time` 与 L339 `.trace .node .time` 为 11px，低于令牌 `--text-micro`（12px）下限，建议提至 12px，保证可读与令牌一致。
2. **玩具几何插画占位**：原型期可接受（扁平几何、品牌色、风格统一）；生产期建议替换为实拍产品图或更精致的品牌插画，提升商品辨识度。
3. **伟易达学习平板插画底使用 danger-tint #FBE4DF**：语义红浅底被用作装饰，建议换为 neutral-tint/primary-tint 等非语义浅色，严守"语义色不混作装饰"纪律。
4. **流程页 Stepper 语义与实际不符**：rental.html 所有区块同时可编辑，但 stepper 标注"2 · 配送信息"为当前步；建议 stepper 仅作线性流程指示（is-done=已完成填写）或改为章节编号，避免误导。
5. **仪表盘订单 2 消毒编号复用订单号**：dashboard.html L278 "已消毒 TS-20250610-0398" 将订单号当作消毒报告号；建议区分 `TS-`（订单）与报告/批次号语义，保证编号体系可信。
6. **饱和色相偏多**：每页同时出现黄/珊瑚/绿/琥珀/蓝 5 色相（多为语义徽章与玩具插画，可接受）；建议玩具插画单件限 2-3 色相，进一步收敛。
