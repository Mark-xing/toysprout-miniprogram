## 二、业务模型说明（v2 交换模型 · 对 v1 租赁模型的全面修订）

> **重要**：本版是对 v1「平台自营租赁（押金 / 消毒 / 质检 / 批次 / 追溯）」模型的**全面修订**，产品语义已全部重做，v1 租赁关键词在产品页零残留。

### 2.1 核心交易模型

- **C2C 一换一互邮**：家长之间直接交换闲置玩具，一单一换一，双方互相邮寄，无平台自营库存、无租赁押金。
- **服务费**：每单 **¥1.9**，**双方发起快递时收取**（非会员）；**会员免单**；「意向未成 / 取消 / 未互寄」不收费。
- **会员订阅**：**单档会员 ¥10 / 月**；权益 = 免每单服务费 + 玩具优先曝光 + 专属客服 + 信用分加成。

> 业务规则已由产品方拍板（2026-08-26）：服务费 ¥1.9 / 双方发起快递时收取 / 会员 ¥10 单档 / 运费协商 / 信用以互评为准 / 实名 = 姓名 + 身份证号。双端原型已按此口径全站更新。

### 2.2 信任三要素体系

| 要素 | 机制 | 落地载体 |
|------|------|---------|
| 人靠谱 | 信用分（500–1000）+ 四级等级（新芽 / 成长 / 信赖 / 优选）+ 实名 / 家长双认证 | 信用分徽章、认证标识、作者卡、互评卡 |
| 物如实 | 成色四级（全新 / 9 成新 / 8 成新 / 有使用痕迹）+ 实拍规范 + 适龄 / 小零件安全标签 | 成色标签、发布实拍约束、安全标签 |
| 平台兜底 | 服务费担保（成功才收取）+ 双轨运单全程追踪 + 异常仲裁入口 + 取消不收费 | 服务费保障条、交换状态机、仲裁入口 |

### 2.3 v2 信任组件族（双端同构同语义同语言）

1. **信用分徽章**：四级色阶 + 专用图标（芽 / 幼苗 / 盾勾 / 星盾）+ 等级名 + mono 分值；
2. **成色标签**：四档 + 图标（礼盒 / 勾 / 半钟 / 折痕），颜色 + 图标 + 文字三通道编码；
3. **互评卡**：星级恒为品牌黄 + 快捷标签 + 差评红底红标签 + 平台回复样式，评价反馈到信用分变化；
4. **交换状态机**：五态（已发起 → 对方已同意 → 双方邮寄中 → 已完成 → 已取消 / 纠纷），进行中节点琥珀呼吸动效，Web 375px 已按令牌转竖排；
5. **服务费保障条**：四变体（非会员 / 会员免单 / 担保中 / 纠纷），统一「¥1.9（会员免）· 双方发起快递时收取」口径；
6. **认证标识**：已实名（盾勾）/ 家长认证（家庭勾），双认证叠于作者卡与玩具卡。

### 2.4 双端差异化

- **Web** = 大屏决策管理：订单分组列表、会员免服务费计算器、权益对照表、落地页营销叙事；
- **小程序** = 移动交互优先：拍照发布、聊天意向卡、会员免切换（¥1.9 ⇄ ¥0）、竖排状态机、评价信用变化卡。

## 三、核心体验主线

> **人靠谱 + 物如实 + 平台兜底**，全站贯通：

- **浏览端信用前置**：任何玩具卡作者行都带认证 + 信用徽章，成色标签直接标在卡角，先看「人」和「物」再决定交换；
- **发布端如实约束**：实拍 ≥3 张、瑕疵特写、自然光提示 + 成色四级必选 + 适龄 / 小零件必填，从源头保障「物如实」；
- **交换端一换一互邮**：交换池单选 + 运费勾选 + 保障条明示费用，交换前费用与规则透明；
- **订单端平台兜底**：五态状态机 + 双轨运单（顺丰双号）+ 服务费担保（成功才收 / 会员免），异常可仲裁；
- **完成端互评反馈**：评价后信用分实时变化（如 862→866 +4），好交换沉淀为信用资产。
