# 家长玩具交换平台（v2 · C2C 交换模型）· 交付概览

> 业务模型修正版 ｜ 品牌「童芽 ToySprout」 ｜ 设计系统「WarmTrust v2」

## 业务模型（v2，替代 v1 租赁模型）

**C2C 家长间玩具交换平台**：家长上传自己孩子的玩具 → 浏览发现心仪玩具 → 与玩具主人聊天沟通 → **一换一互邮**完成交换（A 寄 X 给 B，B 寄 Y 给 A）。平台收取中间介绍费。

- **收入**：每单固定服务费 ¥1.9（双方发起快递时收）+ 会员订阅 ¥10/月（免每单服务费 + 优先曝光 + 专属客服 + 信用分加成）
- **信任三要素**：人靠谱（信用分 500-1000 四级 + 实名认证 + 互评）+ 物如实（成色四级 + 实拍规范）+ 平台兜底（服务费保障 + 纠纷仲裁）
- **运费**：不设固定规则，双方协商（分摊 / 一方承担）

## 交付成果

**Web 端 8 页**（`exchange/web/`）：落地页 / 发现 / 玩具详情 / 发起交换 / 订单列表 / 订单详情 / 我的主页 / 会员订阅
**小程序端 10 页**（`exchange/miniprogram/`）：4 Tab（发现/消息/发布/我的）+ 6 子页（详情/发起交换/订单详情/聊天/评价/会员）

**入口**：Web 打开 `exchange/web/index.html`；小程序打开 `exchange/miniprogram/discover.html`（桌面自动套手机外框，页面互跳）。

## 设计决策（v2 变更）

1. **信任组件族全面重映射**：v1 消毒报告卡/质检徽章/批次追溯条退役 → v2 信用分徽章（四级）/成色标签（四级）/互评卡/交换订单状态机（双轨运单）/服务费保障条/认证标识/安全提示标签
2. **色彩/排版/间距继承 v1**，仅新增 19 个语义色 alias + 1 个新 HEX（信用等级/成色/星级/担保），零自创色值
3. **状态三重编码**：绿=信用高/如实/担保、红=差评/纠纷/逾期、琥珀=进行中/8成新、蓝=信息/物流/9成新
4. **会员口径**：全站设定当前用户为会员 → 订单链路服务费统一 ¥0（会员免单，立省 ¥1.9），无双口径并列
