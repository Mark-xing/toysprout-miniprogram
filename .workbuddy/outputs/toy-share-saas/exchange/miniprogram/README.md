## 互跳闭环
- Tab 4 页互切（TabBar 4 Tab，激活 primary 色，发布中央凸起圆钮）
- 详情 → 发起交换 → 订单详情 → 聊天 → 评价 全链路可达
- 聊天意向卡「同意交换」直达订单详情；订单「联系对方」直达聊天；订单「去评价」直达评价页

## 实现要点
- CSS 变量完整消费 v2 Quick Snippet（§11.3）+ §2.3 语义描边，无自创色值；暖棕阴影
- 状态三重编码：绿=信用高/如实/担保，红=差评/纠纷/逾期，琥珀=进行中/提醒/8成新，蓝=信息/物流/9成新，灰=中性/新芽/取消
- 触达 ≥44px、`:active` 按压态替代 hover、`tabular-nums`/mono 用于信用分/运单/金额
- 无消毒/质检/批次/追溯/押金等租赁模型语义残留
