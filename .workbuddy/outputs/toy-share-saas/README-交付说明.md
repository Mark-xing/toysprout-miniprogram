## 四、核心设计要点回顾

### 1. WarmTrust 设计令牌（Phase 2 权威源，styles.css `:root` 全量落地）
- **色彩**：暖米白底 `#FBF6EC` + 深暖炭文字 `#33291F`（正文对比 ≥14:1）；奶油暖黄 `#F2B33D` 品牌点缀 + 珊瑚橙 `#C94324` 主 CTA；语义色**绿=安全 / 琥珀=进行中 / 红=风险 / 蓝=信息**（全站语义锚定，禁止绿示危险、红示通过）。
- **字体**：标题 Nunito（回退 PingFang SC/思源黑体），正文 Inter 系统栈，编号/批次 mono；数字统一 `tabular-nums`。
- **几何**：4px 间距阶梯、圆角 sm6/md10/lg16/xl24/full、暖棕调阴影（禁冷黑）、8px 圆角进度条。
- **禁则**：无儿童乐园感、无黄色小字正文、无纯黑冷阴影、无装饰底白字、信任信息不做隐藏式承诺。

### 2. 信任可视化组件族（一等组件，四页全站贯穿）
- **消毒报告卡**（详情页完整版 / 仪表盘订单卡内嵌）：左缘绿色标识条 + mono 报告编号 + 质检员工号背书 + 4 步消毒时间戳。
- **质检徽章**：浅底+深字+盾/勾图标，「质检合格 / 检测中 / 待检」三重编码（颜色+图标+文字）。
- **批次追溯条**：6 节点（入库→消毒→质检→配送→使用中→归还复检），完成绿实心、进行中琥珀呼吸动画、未开始灰虚线。
- **安全标识组**：落地页 4 卡横排（100% 消毒 / 质检合格 / 全程可追溯 / 无铅·无 BPA）。

### 3. 价格口径（Round 1 修复后统一）
- **订阅套餐价**：月卡 ¥89 / 季卡 ¥79（¥237/季）/ 年卡 ¥69（¥828/年），**押金统一 ¥100**。
- 详情页租赁档位、流程页费用明细、成功页订单合计三处联动一致；「立即租/选择X卡」按档位携带 `?plan=` 参数跳转并默认选中。
- 口径说明：玩具卡片的 ¥59/月 等为**参考月租**（会员专享价），订阅套餐内含玩具租赁费（详见「已知待办」P1-5 建议补齐「参考」标注）。

### 2. 与 Web 版的差异说明

- **375px 单列**：以 375px 手机视口为设计基准，全站单列纵向布局（Web 版为多栏响应式）。
- **底部 TabBar 4 项**：首页 / 玩具库 / 我的订单 / 我的，仅 4 个 Tab 页常驻底栏；子页（详情 / 订单 / 成功 / 报告）为栈式跳转、左上返回。
- **子页返回**：子页顶部 `nav-back` 返回上一页（如 详情 → 库、订单 → 详情、报告 → 详情）。
- **信任组件移动化**：竖排消毒时间线、纵向批次追溯条、2×2 安全标识网格（Web 版为横排时间线 / 横向追溯条 / 4 卡横排）。

### 3. 新增能力（相对 Web 版）

- **`?plan=` 套餐回填**：详情页/首页携带 `?plan=month|year` 跳转 rental 后，对应套餐卡自动选中并联动费用与按钮文案。
- **首月 5 折（仅月卡首月）**：首页 Banner「新会员首月 5 折」携带 `?plan=month&discount=half`，月卡首月 ¥45 与费用页、按钮联动一致；季卡/年卡不受影响。
- **`report.html` 检测报告页（新增）**：详情页「查看完整检测报告」由 `#` 死链改为真实跳转，报告页展示完整 4 步消毒时间线 + 质检员/批次编号（mono），补全「透明追溯」闭环。
