## 一、业务分析

### 1.1 产品定位

【假设】产品为「面向 C 端家长的玩具订阅制共享平台」+「面向平台运营方的 SaaS 管理后台」双端结构。核心商业模式：家长按月订阅，平台统一采购/回收玩具，经标准化消毒质检后循环流转出租，以「安全 + 性价比 + 可持续」为差异化价值。

- **C 端（家长前台）**：订阅 → 选玩具 → 配送 → 使用 → 归还/续租 → 换新玩具，全流程线上化
- **B 端（运营后台 SaaS）**：玩具库存管理、消毒批次管理、订单履约、会员运营、数据分析

### 1.2 商业模式画布要点（轻量版）

| 模块 | 要点 |
|------|------|
| 价值主张 | C 端：以订阅价远低于买新，持续获得适配年龄的高质量玩具；统一消毒质检、全程可追溯（信任核心）；环保可持续。B 端：新品试用分发渠道 + 用户反馈数据 + 品牌曝光 |
| 客户细分 | 核心：0–10 岁孩子家长（25–40 岁，注重性价比/安全/环保）；次要：玩具品牌商、母婴 KOL/分销 |
| 收入来源 | 订阅费（月/季/年卡）、押金与逾期/损坏赔付、增值服务（生日套装/早教包/礼品包装）、B 端品牌合作与数据服务 |
| 关键资源 | 玩具库存、消毒质检体系、物流网络、会员运营系统、信任背书（检测报告/认证） |
| 关键活动 | 玩具采购与更新、标准化消毒质检、订单履约（租/还/换/续）、会员运营、客服 |
| 关键合作 | 玩具品牌商、消毒设备与耗材供应商、同城/干线物流 |
| 渠道 | 官网、App/小程序、公众号、家长社群口碑 |
| 成本结构 | 玩具采购与折旧、物流、消毒质检人工与耗材、平台研发运维 |

### 1.3 用户旅程与痛点（家长视角）

| 阶段 | 用户行为 | 痛点 |
|------|---------|------|
| 1 发现 | 听说/看到玩具共享 | 不知孩子喜好，买错率高；家里玩具堆积浪费 |
| 2 决策 | 浏览玩具、比较套餐 | **信任顾虑**：二手/共享玩具是否干净安全？平台资质存疑 |
| 3 下单 | 选玩具、提交订阅 | 流程繁琐、会员等级/费用不透明、担心押金规则 |
| 4 使用 | 收到玩具、日常使用 | 损坏界定模糊；孩子玩腻后换新不灵活 |
| 5 归还 | 预约归还/续租 | 归还流程麻烦；「到底消毒没消毒」不可见 |
| 6 留存 | 续费/推荐他人 | 缺乏个性化推荐，孩子成长需求变化未被感知 |

> 设计结论：**信任可视化（消毒/质检/追溯）是贯穿全站的核心体验主线**，而非附属功能。

### 1.4 核心功能模块（首期范围）

1. **订阅与会员**：套餐（月/季/年）、会员等级与权益、自动续费、押金规则
2. **玩具浏览与推荐**：分类、年龄适配标签、智能推荐、心愿单/收藏
3. **租赁订单**：租 / 还 / 换 / 续租、配送追踪、逾期与赔付提示
4. **消毒质检可视化**：消毒流程步骤展示、质检报告卡、批次追溯记录（信任核心）
5. **个人中心/家庭档案**：孩子年龄与偏好、收货地址、账单与发票
6. **客服与社区**：FAQ、在线客服入口、家长评价与晒单
7. **后台运营（SaaS）**：库存、消毒批次、订单、用户、数据看板【二期】

### 1.5 信息架构（首期原型覆盖范围）

```
官网落地页（营销层）
  └─ 价值主张 / 消毒信任 / 套餐订阅 / CTA

平台主界面（应用层）
  ├─ 首页·仪表盘：今日推荐、进行中订单、消毒状态、会员进度
  ├─ 玩具库：浏览 / 筛选 / 搜索 / 分类
  ├─ 玩具详情页：图集、年龄适配、租赁选项、消毒质检报告卡
  ├─ 租赁流程：确认订阅 → 配送 → 归还计划（预约归还/续租）
  ├─ 消毒与安全：消毒流程可视化 + 检测报告（透明化信任页）
  ├─ 会员中心：套餐、等级权益对比、账单
  └─ 账户：家庭档案、地址、设置
```

## 二、需求摘要（五要素框架）

| 维度 | 结论 |
|------|------|
| **场景 Surface** | 多页面 Web 高保真原型：① 官网落地页（营销转化）② 平台主界面/仪表盘（登录后首屏）③ 玩具详情页 ④ 租赁/归还流程页。桌面端优先，信息密度适中、可读性强，为移动端适配预留结构 |
| **受众 Audience** | 核心：25–40 岁家长（0–10 岁孩子），B2C、非技术背景，关注安全/性价比/便捷/环保；审美预期为「现代亲子品牌」而非儿童卡通。次要：平台运营方与玩具品牌合作方（后台示意，二期） |
| **调性 Tone** | **Soft Warm（柔和温暖）为主 + Modern Minimal（现代极简）功能优先为辅**。暖色系（奶油黄/珊瑚橙/暖米白）+ 清新鼠尾草绿点缀；圆角适中、留白充足；避免过度幼稚夸张（不用花哨卡通），克制专业，可信优先 |
| **品牌上下文 Brand Context** | 全新品牌，无现有品牌手册/视觉资产。建议品牌气质方向：**「温暖 · 可信 · 可持续」的亲子陪伴品牌**（示例品牌名：童芽 ToySprout）。主色奶油暖黄 + 珊瑚橙点缀 + 鼠尾草绿（安全/环保语义），正文无衬线、标题可轻衬线点缀 |
| **规模 Scale** | 多页面（首期 4 页，P0×2 + P1×2），静态高保真为主，局部 hover/状态交互，暂不做完整响应式断点与复杂动效（预留扩展位） |

### 推荐方向
- **建议设计系统类型**：Custom 轻量定制 —— 以「Soft Warm」为基座、叠加「Modern Minimal」的组件化细节，产出品牌化设计令牌（颜色/字体/圆角/阴影/间距）
- **建议原型模板**：落地页模板（Hero + 信任区 + 套餐区 + CTA）+ SaaS 仪表盘模板（侧边导航 + 卡片网格）+ 详情/流程页模板
- **特别注意事项**：
  1. **信任可视化优先**：消毒质检报告卡、安全标识应作为全站贯穿元素，而非只存在于详情页
  2. 暖色系需控制饱和度，保证信息层级清晰，避免「儿童乐园感」；正文对比度满足可读性
  3. 所有示意数据（玩具、订单、消毒批次、会员进度）应专业可信，避免空泛占位

## 三、原型页面清单与优先级

| 优先级 | 页面 | 说明 | 关键内容 |
|--------|------|------|---------|
| **P0** | ① 官网落地页 | 营销转化入口，讲清「是什么 + 为什么可信 + 怎么订」 | Hero 价值主张、消毒信任三要素（UV 消毒/质检报告/批次追溯）、订阅套餐卡、CTA |
| **P0** | ② 平台主界面·仪表盘 | 登录后首屏，聚合用户关键状态 | 侧边导航、今日推荐、进行中订单（含消毒/配送状态）、会员等级进度、快捷入口 |
| **P1** | ③ 玩具详情页 | 决策关键页，承载信任与转化 | 玩具图集、年龄适配、租赁选项（本月/季/年）、**消毒质检报告卡**、用户评价、加入心愿单/立即租 |
| **P1** | ④ 租赁流程页 | 转化闭环（下单/确认配送/归还计划） | 确认订阅套餐、地址与配送、归还日期选择/续租提醒 |
| P2 | ⑤ 消毒与安全透明化页 | 品牌信任深化 | 消毒 4 步流程可视化、检测报告、追溯记录 |
| P2 | ⑥ 会员中心 | 等级权益与账单 | 套餐对比、等级进度、账单明细 |
| P2 | ⑦ 后台运营（SaaS Admin）示意 | 面向运营方的数据/库存管理（单页示意即可） | 数据看板、库存、消毒批次、订单列表 |

> **首期交付建议**：P0 + P1 共 4 页；P2 作为二期增强。若时间允许，优先补 ⑤ 消毒透明化页（信任主线）。

## 四、给 Phase 2 的交接要点

1. 设计系统方向已锁定：**Soft Warm 基座 + Modern Minimal 细节**，需产出品牌化设计令牌
2. 品牌气质关键词：**温暖、可信、可持续、亲子陪伴、克制专业**
3. 颜色方向建议（供设计令牌化，非最终值）：主色奶油暖黄 / 珊瑚橙点缀 / 鼠尾草绿语义 / 暖米白背景 / 深炭文字
4. 信任可视化组件（消毒报告卡、安全标识、批次追溯、质检徽章）需要作为**一等组件**纳入设计系统
5. 交付物中所有文本将使用中文，字体栈需覆盖中文字体（如系统字体 + PingFang/思源黑体类）
